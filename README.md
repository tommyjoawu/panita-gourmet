# Panita Gourmet & Bakery — landing

Sitio estático para GitHub Pages. Sin build.

- `index.html` — selector para comparar las 3 versiones (teclas 1/2/3)
- `v1/` — dirección Emil Kowalski (emilkowalski/skill)
- `v2/` — dirección Leonxlnx/taste-skill
- `v3/` — combinación (impeccable + minimalist-ui + emil + web-interface-guidelines)
- `BRIEF.md` — datos del negocio y reglas de copy

Local: `python3 -m http.server 8080` y abrir http://localhost:8080

Cuando se elija la versión final, moverla a la raíz y agregar `CNAME` si hay dominio.
